KOReader for Kobo — install this release
========================================

This zip is already assembled. You do not need GitHub, Python, pipx,
KFMon, or Plato.

Do NOT double-click anything that macOS calls an "app" or ".command".
Apple blocks unsigned scripts downloaded from the internet, and
Right-click → Open often cannot override that.

1. Unzip this archive on your COMPUTER (not onto the Kobo).
   Safari may already have unzipped it. Leave the hidden ".adds" and
   ".kobo" folders alone — the installer uses them.

2. Plug the Kobo in over USB. Unlock it. Wait until a drive named
   "KOBOeReader" appears. Stay on the Home screen.

3. Run the installer:

   macOS and Linux
     Open Terminal, type the word bash and a space, then drag
     install.sh from this folder onto the Terminal window. Press Return.

     Example once you have changed into this folder:

       bash install.sh

   Windows
     Right-click install.ps1 → Run with PowerShell

4. The installer asks to eject the Kobo. Say yes. It will reboot as if
   installing an update — that is NickelMenu being installed.

5. After reboot, tap the **KOReader** tab on the Home screen (not More),
   or open My Books and look for KOReader in that menu.

6. Put .fb2 / .fb2.zip (and other sideloads) in the KOReader folder on
   the Kobo USB volume. Nickel ignores that folder. In KOReader, open it
   and long-press → Set as HOME directory.

Do not drag folders onto the Kobo in Finder or Explorer. Hidden directories
are easy to miss, and that is how installs silently fail.
